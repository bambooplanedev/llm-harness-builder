# Вправа 3: повтор ходу

Необов'язкова. Потрібна qwen3:8b на Ollama ([Підготовка](../README.uk.md#локально)). Близько 10
хвилин.

Прогін `059867d3` (`tuned-nothink`, PASS) записав кожен запит, який надіслав. `replay` надсилає один
із них знову, точно таким, яким його було надіслано, кілька разів, і порівнює відповіді. Жоден
інструмент не виконується, тож нічого з того, про що просить модель, не запускається: для повтору
контейнер не потрібен.

## Кроки

    curl -fLO https://raw.githubusercontent.com/bambooplanedev/llm-harness-builder/main/example-runs/059867d3.jsonl
    npx llm-harness-builder replay ./059867d3.jsonl --turn 2 --n 5 --kind ollama --base-url http://localhost:11434

Хмара тут не підходить: записаний запит називає локальну модель `qwen3:8b` і власні поля Ollama, а
хмарний API отримує його таким, яким його записано.

## Що каже вивід

Поки команда працює, у stderr іде по рядку `sample i/n: same as recorded` або `differs` на кожен
зразок. Після них перший рядок результату каже, скільки зразків надіслано і скільки **різних** відповідей повернулося. Далі — по
рядку на кожну різну відповідь: скільки зразків її дали, чи вона `same as recorded` (та, яку
прогін отримав на цьому ході), чи `differs`, і початок відповіді. Відповіді порівнюються за вмістом
і викликами інструментів, а не за текстом thinking чи id викликів. Відкрийте хід 2 прогону
`059867d3` в інтерфейсі, щоб побачити, якою була записана відповідь.
